# Global Market Watch v1.0 — Baseline

This package is the canonical baseline for Global Market Watch.

## Baseline

- Global stock/exchange support.
- Watchlist and portfolio holdings are independent.
- Portfolio holdings are grouped by stock exchange.
- Transactions are excluded.
- Holdings can be added independently of the watchlist.
- Empty numeric portfolio fields remain editable while typing.
- Portfolio collapses horizontally to a minimal left-side control.
- Auto-refresh supports up to 5 minutes.
- Stock and chart logo placeholders are removed.
- Existing trading-app price/change colors are preserved.
- Existing chart axes and chart behavior are retained.
- Security and local persistence architecture from the fixed build are retained.
- The production-build regression caused by stale US/India dashboard assumptions is corrected.

## Versioning

This is the canonical starting point for future Global Market Watch releases.
