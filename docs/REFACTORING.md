# v1.10 UX cleanup

## Removed

- Option-chain UI
- Options watchlist
- Derivatives watchlist
- Option-chain API route
- Option-chain service method
- Option-related browser persistence
- Option-related styling and documentation

The product is now focused on equities, watchlists, alerts and optional portfolio tracking.

## Settings redesign

The settings area was rebuilt as a compact card-based workspace:

- Workspace identity
- Display toggles
- Refresh interval
- Watchlist management
- Portfolio
- Price alerts
- Backup/import

## Visual system

The primary palette follows the requested Color Hunt palette:

- `#222831` — application background
- `#393E46` — surfaces
- `#00ADB5` — accent/action
- `#EEEEEE` — primary text

The palette reference is the Color Hunt palette specified for this release.
